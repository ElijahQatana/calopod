# Security

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include private calendar data in a report.

Use the repository's private vulnerability reporting flow in the GitHub Security tab. Provide the smallest synthetic reproduction that demonstrates the problem. Do not attach real calendar exports, credentials, tokens, private feed URLs, account identifiers, meeting links, or unredacted logs.

If private vulnerability reporting is unavailable, contact the repository owner through GitHub before sharing details.
